# 旭丘軽音楽部 67期 アーカイブサイト

旭丘高校軽音楽部67期の思い出を保存したアーカイブサイトです。2020年にサービス終了したモバイルスペースから保存されたコンテンツを、モダンなAstroフレームワークで再構築しました。

## 🚀 プロジェクト構成

```text
/
├── public/
│   ├── archived/           # アーカイブされたオリジナルコンテンツ
│   │   ├── html/
│   │   │   ├── bbs/       # 掲示板アーカイブ (1500+ ファイル)
│   │   │   ├── diary/     # 日記アーカイブ
│   │   │   └── profile/   # プロフィールアーカイブ
│   │   ├── _ppic_/        # 画像リソース
│   │   ├── _emoji/        # 絵文字スクリプト
│   │   └── _upimg_/       # アップロード画像
│   └── images/            # 新サイト用画像
├── src/
│   ├── components/        # Astroコンポーネント
│   ├── layouts/           # レイアウトテンプレート
│   ├── pages/             # モダンサイトページ
│   │   ├── index.astro    # ホームページ
│   │   ├── profile.astro  # メンバープロフィール
│   │   ├── diary.astro    # 日記
│   │   ├── photo/         # フォトギャラリー
│   │   ├── song.astro     # 楽曲リスト
│   │   ├── link.astro     # リンク集
│   │   └── real.astro     # REAL掲示板へのリダイレクト
│   └── styles/            # CSSスタイル
├── astro.config.mjs       # Astro設定
└── package.json
```

## 🛠️ セットアップ

### 必要環境
- Node.js 18以上
- npm または yarn

### インストール
```bash
git clone https://github.com/hkoketsu/asahikeion67.git
cd asahikeion67
npm install
```

## 🧞 コマンド

プロジェクトのルートディレクトリからターミナルで実行:

| コマンド                   | アクション                                        |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | 依存関係をインストール                              |
| `npm run dev`             | `localhost:4321`でローカル開発サーバーを起動         |
| `npm run build`           | `./dist/`に本番用サイトをビルド                     |
| `npm run preview`         | デプロイ前にビルドをローカルでプレビュー              |
| `npm run astro ...`      | `astro add`, `astro check`などのCLIコマンドを実行    |

## 📝 技術詳細

### フレームワーク・ツール
- **フレームワーク**: Astro 5.0
- **スタイリング**: Vanilla CSS（レトロWindows風テーマ）
- **ビルドツール**: Vite

### アーカイブコンテンツ
- **オリジナルファイル数**: 2900+ HTML/PHPファイル
- **文字エンコーディング**: Shift-JIS/CP932（オリジナル保持）
- **画像フォーマット**: GIF, JPEG, PNG
- **対応ブラウザ**: モダンブラウザ全般

### マイグレーション詳細
1. **ファイル整理**: ルートディレクトリから`/public/archived/`へ移動
2. **パス修正**: 相対パスから絶対パス（`/archived/_ppic_/`等）へ変換
3. **エンコーディング**: charset宣言を修正（macintosh → shift_jis）
4. **クリーンアップ**: 管理者リンク、広告スクリプト、サービス終了通知を削除

## 🎵 コンテンツ

### ページ（Astro）
- **ホーム**: サイト紹介とナビゲーション
- **プロフィール**: メンバー紹介
- **日記**: 各メンバーの活動記録
- **写真**: バンド活動の思い出写真ギャラリー
- **楽曲リスト**: 各バンドの演奏曲一覧（50曲以上）
- **リンク**: 関連サイトへのリンク集
