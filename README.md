## 🚀 プロジェクト構成

```text
/
├── public/
│   ├── archived/     # アーカイブされたオリジナルHTML
│   └── images/       # 画像リソース
├── src/
│   ├── components/   # Astroコンポーネント
│   ├── layouts/      # レイアウトテンプレート
│   ├── pages/        # サイトページ
│   │   ├── index.astro
│   │   ├── profile.astro
│   │   ├── diary.astro
│   │   ├── photo.astro
│   │   └── song.astro
│   └── styles/       # CSSスタイル
└── package.json
```

## 🧞 コマンド

プロジェクトのルートディレクトリからターミナルで実行:

| コマンド                   | アクション                                        |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | 依存関係をインストール                              |
| `npm run dev`             | `localhost:4321`でローカル開発サーバーを起動         |
| `npm run build`           | `./dist/`に本番用サイトをビルド                     |
| `npm run preview`         | デプロイ前にビルドをローカルでプレビュー              |

## 📝 技術詳細

- **フレームワーク**: Astro
- **元データ**: Shift_JISからUTF-8に変換済み
- **レスポンシブ対応**: モバイル・PC両対応

## 🎵 コンテンツ

- **プロフィール**: 全18名のメンバー紹介
- **日記**: さくらさん日記など活動記録
- **写真**: バンド活動の思い出写真
- **楽曲リスト**: 各バンドの演奏曲一覧
